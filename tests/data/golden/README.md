# Golden outputs

Results of running QBiC-SELEX on the repository's example inputs with the two
example models (`src/qbic_selex/examples/`, also installed with the package). `tests/test_golden.py` re-runs these
scenarios and compares them: effects and all other columns within rtol 1e-6;
z-scores within rtol/atol 1e-5 and p-values within 1e-4 on the -log10 scale
(in `--short-output`, one unit in the 4th significant digit). z and p come
from float32 BLAS products, whose rounding depends on the CPU kernel and BLAS
build: across OpenBLAS kernels on one machine, z differed by up to 4e-7
relative, -log10 p by up to 5e-5, and 3 short-output rows by one last digit.

| File | Command (all `--device cpu`) |
|---|---|
| `A_seq_nostats.csv` | `-v example_input_sequences.csv -m example_models_list.txt` |
| `B_seq_stats.csv` | A + `-c <example covs> --compute-stats` |
| `C_seq_wildcard_stats.csv` | B + `--wildcard A` |
| `D_var_stats.csv` | `-v example_input_variants.csv -m example_models_list.txt -c <example covs> --compute-stats -g hg38.fa` |
| `F_var_short_pval.csv` | D + `--pval 0.001 --short-output --model-map example_model_map.csv` |
| `H_single_stats.csv` | D with only the ETV4 model and its covariance file |

Provenance: generated by v1.0.0 and checked against the pre-1.0 scripts
(`qbic_predict_faster.py`, the version used for the IGVF submission, and the
original `qbic_predict.py`) run with numpy 2.2.6 / pandas 2.2.3 / scipy 1.15.3:

- identical to `qbic_predict_faster.py` within rtol 1e-6 (the `--short-output`
  file byte for byte), both on CPU and on GPU (each compared on the same
  hardware). CPU and GPU results differ from each other by float32 rounding
  (z-scores by up to ~1e-4 relative, at |z| near 0), the same for old and new code;
- within rtol 5e-4 of the original per-variant `qbic_predict.py`, which
  accumulates partly in float64 (largest differences are in z-scores near 0);
- the one intended difference: in `C_seq_wildcard_stats.csv` the two rows
  containing N now have z/p (previously NaN, because the wildcard was not
  applied in the statistics step). Their values equal those the original
  script gives when N is replaced by A in the input.

The example covariance matrices (268 MB) and hg38 are not in the repository.
Point the tests at them with `QBIC_SELEX_EXAMPLE_COVS=<dir>` and
`QBIC_SELEX_GENOME=<hg38.fa>`; tests that need them are skipped otherwise.
The covariances are in `example_covs.tar.zst` on Zenodo
(https://doi.org/10.5281/zenodo.23482275).
